## 先说清楚：云应用到底是个啥

简单讲，雨云云应用是一种基于容器的轻量云服务。你不用买整机，也不用纠结选哪个系统镜像，直接在面板里选个应用模板（可道云、RustDesk、各种 bot、网站环境都有），点几下就部署好了。每个应用独享你分配的 CPU、内存、磁盘，数据持久化存储，重启不丢。

## 几个容易被忽略的计费细节

聊到这里，有几个论坛里用户经常问、但官方文档写得比较零散的点，顺手帮你整理一下：

**停止容器照常计费。** 这是不少人踩的坑。把应用"停止"只是让它不跑了，分配的 CPU、内存、IPv4 资源还在你名下挂着，照样扣钱。真想省钱，得直接把项目删掉，资源才会释放。所以短期不用的服务，别留尸体，删了再建更划算。

**变配要补差价。** 升级配置时，系统会按"距离下一个整点还剩多久"实时补一次差价。比如 14:30 把一个 1 雨点/小时的应用升到 2 雨点/小时，会立即扣半小时的 1 雨点差价，之后整点开始按新配置走。这点对频繁调配置的同学要注意。

**流量按小时、按实际使用量扣。** 最小计费单位是 0.0001 雨点，低于这个值就不计费。内网传输流量不计费，只有公网出入才走流量包。这点对香港机房尤其重要——香港流量是 1 雨点/GB，跑大文件下载的话，流量费可能比资源费还高。

**独立 IP 只能入站，不能出站。** 加购的 IPv4 目前只能做入口转发，出口地址还是共享的，没法指定。如果你的应用需要固定出口 IP（比如对接某些白名单 API），这点得提前考虑。

**持久化存储是有的。** 容器应用的数据会持久化，重启、变配都不会丢。但目前不支持挂载弹性云盘，磁盘容量是在创建/变配时一次性分配的。

## 它和传统云服务器比，到底省在哪

很多人纠结"云应用价格"的时候，其实是在纠结"我到底该买云应用还是云服务器"。这俩不是一回事，适用场景也不一样。

云服务器是整台机器租给你，配置固定、价格固定、你爱怎么折腾怎么折腾，适合长期满载运行、需要 root 权限、需要装一堆自定义软件的场景。雨云的云服务器入门款 1 核 1G 大概 20 元/月起，年付 7 折后月均更低。

云应用是按资源维度拆开卖，配置随时升降、用多少付多少，适合轻量、弹性、不需要完整系统权限的场景。如果你只是想跑个 bot、挂个静态站、部署个容器化应用，云应用的月费往往比同档云服务器还低，而且不用为闲置的 CPU 付费。

一句话总结：**长期满载、要折腾系统的，选云服务器；轻量弹性、按需启停的，选云应用。** 预算特别紧、又想多试几个项目的，云应用的按小时计费模式几乎是为这类需求量身定做的。
